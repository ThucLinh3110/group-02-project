# Project Vault Index

- **Dự án**: AI-Assisted IT Helpdesk Management System
- **Owner**: Luy (Vai trò: AI / Vault Engineer)
- **Mục tiêu**: Làm nguồn dữ liệu chuẩn (Single Source of Truth) để AI đọc hiểu và phản hồi có kiểm chứng.

## Cấu trúc thư mục hệ thống tài liệu
Dự án được chia thành 2 thư mục chính:

### 1. `docs/` (Tài liệu tổng quan & Bàn giao)
- `PRD.md`, `ARCHITECTURE.md`, `API.md`, `TRACEABILITY.md`
- `team-roles.md`, `source-priority.md`
- `AI_USAGE_LOG.md` (Nhật ký AI)

### 2. `vault/` (Project Vault - Kiến thức chuyên sâu theo Phase)
- `01-Requirements/`: Đặc tả yêu cầu, báo cáo, user research.
- `02-Research/`: Phân tích scope, stakeholders.
- `03-Product/`: Thuật ngữ hệ thống, business rules.
- `04-User-Stories/`, `05-Design/`, `06-Engineering/`: Thiết kế chi tiết.
- `07-QA/`: Test strategy, code review, matrix.
- `08-Decisions/`: Nhật ký quyết định.
