| Thành phần PRD | Nội dung chi tiết |
| :--- | :--- |
| **1. Problem** | Nhân viên báo lỗi IT khó theo dõi. Quản lý tốn thời gian chia việc thủ công, dễ sót vé và trễ hạn SLA. |
| **2. Goals** | Tự động hóa tiếp nhận lỗi (G1); Cảnh báo SLA (G2); Hỗ trợ trả lời bằng AI (G3). |
| **3. Non-goals** | Không tự sửa lỗi (Auto-remediation); không xử lý ngân sách thiết bị. |
| **4. Users** | Employee; IT Agent; IT Manager. |
| **5. Functional Scope** | Đáp ứng toàn bộ REQ-HD-01 đến REQ-HD-05. |
| **6. Business Rules** | Tuân thủ tuyệt đối BR-HD-01 và BR-HD-02. |
| **7. UX Principles** | Trạng thái vé hiển thị rõ. Cảnh báo SLA bằng màu nổi bật. Hành động xóa/đóng cần Confirm. |
| **8. Metrics** | Tỷ lệ AI gán nhãn đúng > 80%. 5 luồng E2E chạy thành công. 100% vé trễ hạn hiện Overdue. |
| **9. Risks** | LLM Timeout; Prompt Injection; Mô tả lỗi của User quá ngắn. |
| **10. Release Slice** | MVP-1: Triển khai 5 Story cốt lõi của nhóm. |
