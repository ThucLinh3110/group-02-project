**MVP Scope**

| Must | Should | Could | Out of Scope |
| :--- | :--- | :--- | :--- |
| Giao diện tạo vé báo lỗi bằng văn bản/hình ảnh | Khung chat trực tiếp trong chi tiết vé | Thống kê tỷ lệ lỗi theo phòng ban | Tích hợp tổng đài điện thoại (Call-center) |
| Dashboard thống kê và quản lý vé cho IT Manager | Chức năng Admin quản lý bài viết Knowledge Base | Cho phép người dùng đánh giá (Rating) sau khi xử lý xong | Quản lý vòng đời tài sản phần cứng chuyên sâu |
| AI tự động đọc vé và gán nhãn danh mục/ưu tiên | | | Tự động hóa quy trình sửa chữa (Auto-remediation) |
| Hệ thống đếm ngược SLA và cảnh báo màu sắc | | | Xác thực bằng sinh trắc học |
| AI gợi ý câu trả lời từ Knowledge Base cho Agent | | | Xử lý các lỗi ngoài phạm vi IT (nhân sự, lương thưởng) |
